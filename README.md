## 📋 About

**SCP Automation** is the operations backbone of the SCP platform. It integrates Gmail APIs for email automation, Firebase Cloud Functions for serverless compute, PowerShell scripts for remote system management, and a sleek web frontend for visual control. Automate everything — from email workflows to SSH deployment.

> ⚡ *Automate once. Run everywhere.*

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/your-org/scp-automation.git

# Navigate to the project
cd scp-automation

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your credentials

# Start the server
npm start

# Run tests
npm test
```

## 📁 Project Structure

```
scp-automation/
├── 📄 index.js                  # Main server entry point
├── 📄 gmailAuth.js              # Gmail OAuth2 authentication
├── 📄 credentials.json          # API credentials config
├── 📄 enable_ssh.ps1            # PowerShell SSH setup script
├── 📄 firebase.json             # Firebase hosting config
├── 📂 frontend/                 # Web dashboard UI
├── 📂 functions/                # Firebase Cloud Functions
├── 📂 services/                 # Automation service modules
├── 📂 templates/                # Email & task templates
├── 📂 gif/                      # Animation assets
├── 📂 public/                   # Static web assets
└── 📂 assets/                   # Images, logos & branding
    └── 3d-logo-spinning.gif     # SCP animated logo
```
