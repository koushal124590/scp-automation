Obtaining Google Credentials

To allow this automation tool to read and reply to your emails, you must provide OAuth 2.0 credentials.

  1. Go to the Google Cloud Console.
  2. Create a new Project.
  3. Enable the Gmail API in the APIs & Services library.
  4. Navigate to OAuth consent screen and configure it (set to External, add your email as a test user).
  5. Go to Credentials > Create Credentials > OAuth client ID.
  6. Select "Desktop app" (or Web application) and create.
  7. Click Download JSON and rename the file to credentials.json.
  8. To generate token.json, run the initial authorization flow on your backend or local node server.
